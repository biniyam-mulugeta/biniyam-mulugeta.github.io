⚙️ Site Admin Setup

This admin panel uses the GitHub API to save changes directly to your repo — no server needed. Changes go live on your GitHub Pages site within ~60 seconds.

You need a GitHub Personal Access Token with Contents: Read & Write permission.

1.Go to GitHub → Settings → Developer Settings → Fine-grained tokens
2.Create token with Contents: Read & Write for your pages repo
3.Paste the token below — it's stored only in your browser
